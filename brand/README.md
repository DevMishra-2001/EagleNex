# EagleNex Brand Kit

## Files

| Use | File |
|---|---|
| Website / dark backgrounds | `svg/eaglenex-logo-horizontal.svg` |
| Letterhead, visiting card, light backgrounds | `svg/eaglenex-logo-horizontal-dark.svg` |
| Office signboard / reception wall (vertical space) | `svg/eaglenex-logo-stacked.svg` / `-stacked-dark.svg` |
| Single-colour print (stamp, engraving, embroidery, glass etching) | `svg/eaglenex-logo-horizontal-mono-black.svg` / `-mono-white.svg` |
| Only the eagle (merch, stickers, watermark) | `svg/eaglenex-mark*.svg` |
| App icon, favicon, social media profile picture | `svg/eaglenex-app-icon.svg` / `-dark.svg` |

- `svg/` — vector, infinitely scalable. **Always send these to the printer / signage vendor.**
- `png/` — 2000 px, transparent background, for Word, PowerPoint, WhatsApp, etc.
- The text is converted to outlines, so it looks the same everywhere without installing a font.

## Fonts

- Logo wordmark and UI text: **Plus Jakarta Sans** (Bold)
- Headings: **Sora**
- Accent words: **Instrument Serif** (Italic)

All three are free Google Fonts.

## Rules

- Keep empty space around the logo of at least the height of the eagle's head (~25% of the mark height).
- The mono versions are solid single-colour. The thin gaps between the facets carry the detail, so don't fill them in.
- Minimum size: mark 16 px, horizontal logo 100 px wide (print: 25 mm).
- Don't stretch, rotate, recolour the gradient, add shadows, or put the gradient logo on a busy photo. Use the mono version there instead.
